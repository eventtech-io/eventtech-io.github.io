# Event Tech Research Ltd, fully embedded edition

Extract this ZIP and upload its contents to your GitHub repository root. Keep all HTML page folders and .nojekyll. Select Settings > Pages > Deploy from a branch > main > / (root).

Every page embeds its styling and images. The NodeScope page embeds the animated film directly, including its scripts and fonts. No media folder or image folder is needed for page display. The standalone film is also included so its Open film link works. Page-to-page links and downloadable PDFs remain included local files.

The film is the supplied HTML animation with playback controls, not an MP4. No build step, server, CDN or remote font service is required. The code walkthrough is excluded.
