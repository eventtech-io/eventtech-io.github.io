NodeScopeRF Quick Start

Get started with the Event Tech Research RF monitoring demo. Monitor up to eight channels and connect one iPad or other remote browser session.

1. Install and launch

  1. Download NodeScopeRF.exe using the button above.
  2. Keep the download in a folder you can find, then double-click the executable to launch it. If a future download is supplied as a ZIP, extract the entire folder before running the executable and keep any supporting files together.
  3. If Windows shows a security warning, verify that the file came from the Event Tech Research website before deciding whether to run it.

2. Try it without hardware

Demo Mode displays simulated information so you can explore the interface without wireless receivers.

  1. Launch NodeScopeRF and choose Actions → Toggle Demo Mode.
  2. Select a demo audio device in the device dropdown, if offered.
  3. Select up to eight channels.
  4. Choose Start Services or press Ctrl + S.

Simulated information is for familiarisation and is not a live receiver reading.

3. Connect Shure receivers

This demo is intended for Shure Axient Digital and ULX-D monitoring.

  1. Connect the Windows computer and receivers to the same accessible control network.
  2. Launch NodeScopeRF and start services with Ctrl + S. Allow time for discovery; press F5 to refresh the device list if needed.
  3. For optional audio listening, run Dante Virtual Soundcard or a compatible audio interface, route the receiver audio to the computer with Dante Controller, and select the correct audio device in NodeScopeRF.

RF status and listening are separate: the control network supplies receiver information; a suitable audio route is needed to hear microphone audio.

4. Read the monitoring screen

Where available, a channel can show audio level, RF signal, battery status, operating frequency, connection state and warnings. Use these indicators to spot channels needing attention during a sound check. Validate critical readings against the receiver and by listening.

5. Use Mic Check Mode

Press F6 to enter Mic Check Mode, select a channel and mark its check status: 1 OK, 2 Watch or 3 Fault. Press Esc to exit.

6. Connect one iPad or remote device

  1. Connect the remote device to a network that can reach the NodeScopeRF computer.
  2. Enable the WebUI server under Actions and permit remote clients in its settings if required.
  3. Find the computer's local IP address. In a browser on the remote device, enter http://192.168.1.100:8082, replacing 192.168.1.100 with that computer's actual IP address.

The example uses port 8082; use the port shown in your installed configuration if different. On the computer itself, try http://localhost:8082. The demo permits one remote browser session at a time.

8. Troubleshooting

Receivers do not appear

Check network reachability between computer and receivers, check Windows Firewall, then press F5.

RF data appears but I cannot hear audio

Check Dante Virtual Soundcard or your chosen interface, the audio routing, and the selected device in NodeScopeRF.

The iPad cannot connect

Check network access, the remote WebUI setting, computer IP address, configured port and firewall access.

I do not have receivers

Enable Demo Mode and explore the simulated channels.

About this demo. NodeScopeRF Shure Edition is for evaluation and feedback, with up to eight channels and one remote connection. It should not be the sole source of monitoring for a live production.
