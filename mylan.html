+ The job

CONNECT THE KIT.
ASSIGN THE ADDRESSES.

A small show network still needs a clear address plan. MYLan gives crews a way to run DHCP from a laptop, without adding a dedicated router just to assign addresses.

Connect your laptop and show equipment to your own switch, select the wired adapter, choose the address range and start the server. Devices configured for DHCP can request an address and appear in the Active Leases list.

MYLan is an address server, not an internet router. Gateway and DNS are blank by default. It requires administrator permissions to configure the selected adapter and run DHCP.

+ How it works

ONE SWITCH.
A CLEAR STARTING POINT.

  1. 01 / Connect

    Build your own network.

    Connect the laptop and show devices to an isolated switch. Keep this network separate from the venue, office or hotel network and any other DHCP server.

  2. 02 / Configure

    Choose the adapter and pool.

    Select the connected wired port. Check the server address, subnet and address pool against any static addresses already used by your equipment.

  3. 03 / Run

    Start and watch the leases.

    Start DHCP, confirm devices appear and follow the activity log. Stop the server at the end; MYLan attempts to restore the adapter’s previous configuration.

+ Operator tools

SEE WHAT JOINED.
UNDERSTAND WHAT HAPPENED.

Configurable addressing

Set the server IP, subnet and pool. The guide’s default pool runs from 192.168.1.50 to 192.168.1.150, providing 101 addresses.

Active leases

Match issued addresses to device MAC addresses. Saved leases help devices retain their assignments across restarts, without guaranteeing a fixed address.

Readable activity

Follow DHCP requests, offers and acknowledgements. The log also surfaces exhausted pools, declined addresses and requests intended for another server.

Adapter checks

Choose from connected wired interfaces and check for overlapping address ranges on other connections before starting.

Static kit alongside DHCP

Keep manually assigned device addresses outside the DHCP pool and avoid the server address. Plan the range before connecting show equipment.

Start and stop controls

Settings are locked while the server runs. Stop before making changes, and confirm the adapter settings have been restored when you finish.

Windows & macOS

The release provides a Windows x64 installer and portable package, plus Mac packages for Apple Silicon and Intel. Extract the downloaded ZIP first, then follow the included installation steps.

Windows 10/11 and macOS 12 or later are described in the guide. On macOS, install using Install MYLan.command and launch with Run MYLan.command.
